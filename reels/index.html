Break down any reel

Drop in video files. Zephyr measures every cut, short zoom, on-screen text, graphic screen and sound bump, then packs it into a short text plus a few picture strips for Claude to judge. It all runs on your computer and it's free.

Timestamped wordsCuts & zoomsOn-screen textGraphic screen buildsSound bumpsCheck-these list

  1. Copy text and paste it into Claude.
  2. Get images: pick a folder once; the pictures (and the sound clips, in a "sounds" folder) are saved there. Open the folder, select all the images and drag them into the same Claude message. (Or use Download .zip, or the small Copy button under each picture.)
  3. The first run downloads free analysis models (text reader, face finder and speech model). After that they're cached and start fast.
  4. Keep this tab in front while it works; it runs slower in the background.
